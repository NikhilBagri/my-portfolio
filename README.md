# My Portfolio

## Run
npm run dev  → http://localhost:3000

## Edit
- data/site.js    → name, bio, socials, stats, contact, fun toggles
- data/videos.js  → your videos (MP4 / YouTube / Vimeo)
- data/skills.js  → skills + tools
- app/globals.css → colors (@theme)
- app/layout.js   → fonts + SEO
- app/page.js     → section order

## Add files
- public/videos/      → .mp4 files  (src: "/videos/name.mp4")
- public/thumbnails/  → thumbnails  (thumbnail: "/thumbnails/name.jpg")
- public/images/      → your photos
- public/resume.pdf   → resume download
- public/og.jpg       → social share image (1200×630)

## Contact form
formspree.io → New Form → copy ID → data/site.js → contact.formspreeId

## Deploy
Push to GitHub → import on vercel.com → Deploy.
